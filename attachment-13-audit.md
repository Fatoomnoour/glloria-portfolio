## Important constraints and remaining work

The site deliberately remains a client-rendered Vite SPA. A project-detail URL can refresh successfully through the configured fallback, but per-project HTML title, Open Graph tags, and JSON-LD cannot be crawler-specific without SSR or prerendering. The static metadata therefore describes the studio, not individual portfolio entries. This is documented as a limitation rather than overstating SEO coverage.

The current `robots.txt`, `sitemap.xml`, canonical/Open Graph metadata, and `LocalBusiness.@id` use the existing Manus host. They must be changed together only after Vercel produces a confirmed `*.vercel.app` host and one canonical host is selected. No Vercel deployment URL is asserted in this report.

The approved image URLs are resolved by a storage proxy. A Vercel project must receive both `BUILT_IN_FORGE_API_URL` and `BUILT_IN_FORGE_API_KEY` if it is expected to serve those existing assets. The source image files and dimensions were not available in the repository, and a network probe of the production storage path exceeded its timeout; as a result, no speculative AVIF/WebP derivative pipeline was introduced.

The initial mobile direct-route runs revealed a **0.345–0.346 CLS** caused by the shorter lazy route loader yielding to a fully rendered page. Reserving viewport-height space for that loader resolved the sampled mobile project and booking CLS to **0**. Separating charts manually proved counterproductive because the public project route fetched the 407 kB chart chunk; that manual chart chunk was removed, leaving charts inside the lazy admin path.

The remaining mobile performance constraint is predominantly LCP/FCP under Lighthouse’s throttled profile and unused-JavaScript estimates for the editorial shell/data runtime. Source image dimensions could not be inspected from the repository or the timed-out storage probe, so image derivatives were not invented. A Vercel-hosted rerun with real storage credentials and field analytics is still required before claiming production Core Web Vitals.
