# ⚠️ الصور لم تصل إلى مساحة العمل

شُفت الصور في المحادثة، لكنها **لم تُحفظ على قرص السيرفر** — الرسالة أشارت إلى `/home/user/uploads/` والمجلد غير موجود:

```
$ ls /home/user/uploads
ls: cannot access '/home/user/uploads': No such file or directory
$ find / -iname "*.jpeg" -newermt 2026-01-01
(لا نتائج)
```

فمقدرش أحوّلها أو أضغطها أو أضيفها للمستودع. محتاج تبعتها تاني.

## الخط جاهز ومُختبر

جهّزت `scripts/ingest-images.sh` — بيحوّل الأصول إلى نسخ WebP متجاوبة ويطبع أكواد TypeScript جاهزة للصق:

```bash
scripts/ingest-images.sh ~/uploads/boska project-boska landscape
```

مُختبر على مدخلات عرضية وطولية:
- **عرضي** → 480 / 768 / 960 / 1200 / 1600 px
- **طولي** → 480 / 640 / 800 / 1000 px
- لا يكبّر الصورة فوق مقاسها الأصلي، يصحّح الدوران، يحذف بيانات EXIF (فيها موقع GPS أحياناً)، جودة 82

عيّنة مخرجات فعلية من الاختبار:
```
"/images/project-pipetest-02-1600w.webp": {
  width: 1600, height: 1067,
  srcSet: ".../480w.webp 480w, ... 1600w",
},
```
